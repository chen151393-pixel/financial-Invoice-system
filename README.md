# NS 发票中心网页原型

这是一个中文企业后台风格的交互式前端原型，展示 NS 与柠檬云对接后的发票管理流程。

## 核心视图

- 发票工作台：开票进度、已开票 / 未开票金额、自动匹配率、异常池
- 进项发票：柠檬云来源、匹配置信度、关联方式和状态筛选
- 自动匹配详情：子采购单关联、一票多单 / 一单多票、匹配依据和差额核对
- 异常发票处理：异常分类、风险等级、差异对比和处理建议

## 本地预览

需要 Node.js 22.13 或以上版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可预览。生产构建检查使用：

```bash
npm run build
```

本原型使用模拟业务数据，不会连接真实的柠檬云或 NS 数据。
