# 发票导入界面

已移除发票页的票面线索核对区域及其专用组件、样式；后端只读来源接口保留。

`InvoiceImport.tsx`支持将单个文件拖入虚线区域或点击选择文件，展示加载、异常、预览、冲突和真实提交结果；`api.ts`复用公共HTTP客户端上传原文件；样式限定在`invoice-import`内。拖入只选择文件，仍须预览与确认；忙碌时禁止更换文件，多文件拖入会提示重选。

拖拽与点击选择共用同一文件状态，统一展示已选文件名，避免原生输入框仍提示“未选择文件”。取消选择或误拖文字不清除已选文件；重新选择相同文件也会清除旧预览，要求重新核对。文件类型、大小和内容继续由后端校验。

由应用装配层嵌入`/sync/lemon`，复用同步页及AppFrame。前端不解析发票、不计算金额，不依赖NS连接即可加载导入配置。操作能力、计数和去重均来自后端，变更文件会使旧预览失效；请求失败后须重新预览。键盘可通过左右查看按钮滚动宽表。

支持柠檬云数电进项XLS及XLSX，仅导入原表业务类型为“采购固定资产”的发票，预览显示跳过数量及筛选范围内金额。筛选在后端执行，不修改原类型。API及附件同步待接入。记录保存到数据库，当前界面不是持久历史列表，刷新后需要重新选择文件。后端契约见[发票模块](../../../backend/modules/invoice/README.md)。

验证：build、lint、typecheck、check:architecture；使用隔离MySQL及虚构XLS检查上传、预览、确认、重复、错误及桌面/窄屏布局，不做真实NS写入。

支持任意工作表名的34列票头商品合并表，也保留原双表模板。票号归组及合计行排除均由后端处理。

## 真实进项发票页

`InvoiceList.tsx`通过本模块api调用真实列表与详情接口，`invoice-list.css`限定页面样式；`InvoiceWorkspacePage`复用AppFrame。正式路由`/invoices`，兼容`/demo?view=invoices`并替换地址，菜单及导入成功提示进入正式列表。已移除旧模拟InvoiceList组件；模拟匹配等其他页面保持演示状态。

搜索、状态及日期筛选、分页与金额统计均由后端提供。展示未知币种及待核实状态，不填充模拟置信度、抵扣金额或NS关联。列表加载时清除旧结果；过期请求不回写UI。商品详情按需读取，列表宽表保留原生横向滚动，详情同样使用原生横向滚动。

页面沿用四栏指标、匹配状态标签、紧凑搜索筛选栏和双行发票表格。价税合计与票数来自列表接口的当前筛选汇总，未知币种不添加人民币符号。抵扣、匹配与异常统计尚未有业务来源，保留位置显示未接入；相关标签与筛选禁用并说明原因。票面状态和日期筛选位于“更多筛选”，选择框仅管理本页勾选，不触发业务操作。

列表分页沿用页面配色，展示真实总条数、每页10/20/50/100条、页码与省略号、前后页箭头及输入页码后回车跳转。切换每页条数返回第一页，搜索和筛选保留每页条数；每次翻页重新调用后端接口。已移除列表左右查看列按钮及其无用引用。

“查看”进入 `/matching?invoiceId=...` 的真实只读试匹配页；“票面详情”打开右侧抽屉。当前试匹配不等于确认分配，规则及范围见[匹配页面](../matching/README.md)。

票面详情使用原生模态dialog右侧抽屉，桌面宽度76vw（最大1240px）、小屏全宽；背景遮罩阻止列表交互，抽屉内独立滚动，Esc或右上角关闭，关闭后恢复触发按钮焦点及背景滚动。票头采用双列标签／值网格，商品明细与关联信息分区展示；采购关联显示真实匹配摘要并提供详情入口，付款仍标记未接入。

列表取得当前页后，调用匹配模块 `POST /api/matching/summaries` 批量读取关联方式、定性置信度、匹配校验和展示状态，不在前端计算。支持未关联、人工关联、数量分配、已确认（有差异）及来源变化待复核；未保存的候选始终是未关联。原始票面状态与导入数据校验保留，人工确认不代表税务查验通过。摘要独立处理加载和失败，失败可通过“刷新数据”重试，返回浏览器缓存页时重新查询。
