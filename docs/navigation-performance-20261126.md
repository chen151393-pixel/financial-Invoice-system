## 已完成与待验证

已完成本地代码优化、查询响应等价性对比、相关回归和加载外壳检查。没有部署、重启线上服务或执行真实 NS 写入。

## 修改范围

- identity：同一 HTTP 请求复用已校验身份、角色和页面授权，省去第二次读取。每个新请求仍实时校验停用、同步范围、角色与页面授权；无跨请求权限缓存。
- matching / review：整票队列批量读取完整分配与来源，复用同一连接已读取的采购上下文；100% 评估、异常筛选和分页复用本次请求的整票视图。海关列表批量读取当前 NS 来源和历史审核，提交仍在锁内重新比对、核对摘要与令牌。
- source：增加完整来源批量读取和工作台轻量名称读取；最新 JSON 依据先按身份取最大主键，再读正文。单张和批量组装共用规则，保留行序、重号、有效关联、缺失与停用记录的原语义。
- task：工作台只读展示需要的任务行与来源名称；节点沿用现有事实判定。应收看板先限定实际发送过通知的任务，再读取明细，保留完整首次通知历史。前序已完成供应商合并详情批量读取，以及任务台先判断节点、再加载当前页完整资料。
- settlement：报关应收汇按香港批次、直接收汇单票、资料组三类作用域批量读取资料。筛选命中部分组成员时仍读取完整组，收汇分摊仍基于完整历史，金额与齐全度规则不变。
- 前端：业务请求直接由后端认证，删除导航中串行等待的额外会话检查、无调用方的 `openLocalSession` 别名及失效会话的重复只读请求包装。相关读取透传取消信号，切换、重新查询和卸载时取消旧客户端请求。服务端已经开始的查询不保证随之中止。
- 前端装配：任务、结汇按子页拆分下载；路由代码加载时复用现有 AppFrame、导航和 Skeleton，保留中文加载提示。未更换设计或业务操作。

关键入口：[身份依赖](../backend/core/dependencies.py)、[整票查询](../backend/modules/matching/service/matching_query_service.py)、[海关列表](../backend/modules/review/service/customs_receipt_service.py)、[来源快照](../backend/modules/source/service/declaration_service.py)、[工作台任务读取](../backend/modules/task/service/workbench_reader.py)、[应收看板](../backend/modules/task/service/recovery_service.py)、[结汇资料读取](../backend/modules/settlement/service/document_reader.py)、[加载外壳](../frontend/src/app/WorkspaceLoading.tsx)。相关模块 README 已同步更新公开读取方式与边界。

## 计时方法与数据

同一台机器、同一份本地业务数据；连接设置 `SET SESSION TRANSACTION READ ONLY`，直接调用实际服务及其实际只读依赖，不启动应用后台任务、不调用外部集成。每例先预热一次，再测三次取中位数，同时记录 SQL 次数。统计范围包含服务读取与组装，不包含 HTTP、TLS、身份校验和浏览器渲染；身份另测七次中位数。
