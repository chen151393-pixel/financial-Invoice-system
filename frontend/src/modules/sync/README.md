# 数据同步页面

`/sync` 提供数据源卡片；`/sync/ns` 独立提供采购订单、子采购订单、报关单拉取；`/sync/lemon` 提供已有柠檬云账号绑定和数电进项 XLS 文件导入，发票 API 与附件同步仍未接入。旧模拟同步页面及虚构任务记录已移除。

SyncOverview.tsx 保留原同步中心的三列平台卡片、对账数据管道及任务记录表布局；点击 NS 或柠檬云卡片进入对应同步页，子页面可返回中心。尚未接入的统计和任务历史显示明确空状态，不展示虚构记录。

SyncPage.tsx 管理 UI 和请求状态，api.ts 提供请求契约，sync.css 限定模块样式。SyncWorkspacePage 装配公共 AppFrame。复用 identity 本机会话和 shared HTTP 客户端。

公共 HTTP 客户端对空响应、非 JSON 错误页和网络中断显示中文提示；有效的后端错误说明继续展示，不回显代理原始正文。错误不触发自动重试，可通过“重新加载配置”手动重试。`npm.cmd run test:web` 覆盖响应解析与网络失败，已纳入 `npm.cmd test`。

NS 日期拉取：填写开始与结束日期，点击“拉取时间段数据”或“拉取时间段并保存”，页面按后端游标自动串行拉取所有批次，每批最多 20 张。仅拉取不入库；保存复用 source 保存服务，按批提交，标准采购订单仍因缺少独立存储映射禁用保存。进度显示已完成批数；可翻看各批响应，保存计数只代表当前批次，不跨批汇总或冒充去重总量。

拉取并保存同时按NS报关引用补齐对应子采购，并保存可读取的原始报关行、装箱明细及采购行关联依据。页面展示后端 `storage.relations` 统计和 `warnings`：已读取、待补齐及来源行数；依据读取不代表匹配完成或审核通过。原始报关行接口未部署时明确显示待补齐，不用“完整同步”掩盖缺失。

页面保留各类型本次已完成批次的展示结果，刷新清除展示；保存成功的 MySQL 数据不会随刷新丢失。保存连接中断时提示先核实本地数据，不自动重试。当前没有本地历史浏览页面；已保存的报关单在财务核对页（`/review`）查看。柠檬云文件导入由应用层装配[发票组件](../invoice/README.md)，先预览再确认，结果来自真实数据库；不把文件导入称为API同步成功。

NS 子页面仅展示 NS 内容与返回中心入口。使用原生单选控件选择单据类型，默认报关单；每次只显示当前类型的拉取面板。切换时保留各类型的请求及结果状态，不自动拉取，不混入其他平台入口。

NS 页面采用左侧单据选择、右侧结果工作区，窄屏改为上下布局。结果区集中展示拉取操作、只读标识、加载反馈与空状态；不可拉取时展示后端原因，失败后保留已有结果。底部说明结果仅在当前页面保留。

创建日期范围包含起止当天，按 NS 查询时区筛选；当前页面日期必填，校验由后端执行。“清空日期”只修改条件，不自动请求。运行中禁用条件和类型切换。“停止后续拉取”等待当前响应后停止，不中断保存请求；失败不自动重试，已完成批次与已提交数据保留。离开页面不继续发起新批次，但正在处理的批次可能已保存，需核实；没有持久后台任务。只有收到 hasMore=false 才显示整个时间段完成。查询期间 NS 数据仍可能变化，不承诺不可变快照。

接口及配置见 [后端同步模块](../../../../backend/modules/sync/README.md)。验证使用 build、lint、typecheck 和浏览器页面检查；后端模拟测试覆盖成功及空结果，真实 NS 联调单独验收。

柠檬云页由应用层的 `SessionProvider` 共享会话，`RequireSession` 在未登录时跳转至 `/login`，登录后显示 `LemonBindingPanel` 与发票导入组件。绑定面板仅展示后端 allowed/reason；输入手机号后跳转官方授权页，返回后核对手机号并提交账号密码确认。`lemon-api.ts` 维护请求契约；失败先读取实际状态，不自动重复提交。刷新状态、核实已有绑定和配置缺失提示均使用真实后端结果。操作说明见[账号绑定](../../../../docs/lemon-account-binding.md)。

实现：`PullPanel.tsx` 收集条件并展示状态，`useRangePull.ts` 管理请求与批次，`range-pull.ts` 串行调用，`PullResults.tsx` 展示单批结果。`tests/sync-range.test.mjs` 覆盖跨批、失败、停止、空结果与日期保持。

柠檬云绑定工作区按“当前状态与操作 / 官方授权步骤”分栏展示，窄屏按阅读顺序上下排列。配置不满足后端条件时只显示原因与管理员配置说明，不展示无法提交的手机号表单；已有绑定可核实，结果未知不提供重新提交入口。底部明确发票自动拉取尚未接入，可跳至原有 Excel 导入。`useLemonBinding.ts` 管理请求与刷新时的过期响应，`LemonBindingView.tsx` 只展示状态、收集输入；密码在提交及刷新时清空。
