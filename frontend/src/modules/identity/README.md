# 工作台登录

## 路由与文件职责

- `routes.tsx` 注册独立登录页 `/login`，路径集中在 `app/paths.ts`，由 `app/router.tsx` 汇总。
- `pages/LoginPage.tsx` 与 `pages/login.css` 展示登录页，复用现有品牌、设计变量和 Button；支持密码显隐、忙碌禁用、加载与失败状态、失败后的键盘焦点恢复，以及窄屏布局。登录样式仅作用于本页；不在业务页面地址下渲染登录表单。
- `SessionProvider.tsx` 与 `hooks/useSessionState.ts` 统一管理会话检查、登录、退出和 401 失效通知。
- `RequireSession.tsx` 保护业务路由：未登录或会话失效时替换导航到纯 `/login`，原路径、查询参数与锚点只保存在浏览器路由状态中，不附加到登录 URL。
- `login-navigation.ts` 处理登录回跳：登录成功返回路由状态中的 from，直接进入 /login 则返回默认首页；访问带旧查询参数或锚点的登录地址时，先替换为纯 /login。外部地址、无效地址、登录页自身均回退首页，避免外部跳转或循环跳转。
- `SessionMenu.tsx` 通过 `app/WorkspaceFrame.tsx` 装配退出入口。退出成功后跳转登录页；失败保留业务页面并显示错误。共享框架只接收展示插槽，不依赖 identity。

## 接口与约束

`api.ts` 提供 `GET/POST/DELETE /api/session`。兼容函数 `openLocalSession` 仅检查现有会话，不再调用本机免密接口；待现有业务调用方统一迁移命名后删除该别名。柠檬云页复用全局登录，其授权密码由业务表单独立收集。

登录请求期间禁用输入与按钮，密码提交后清空，不存入本地存储，不自动重放凭据。认证规则、来源及权限校验由后端负责。会话由 HttpOnly Cookie 保存，8 小时后失效，后端重启需要重新登录。账号在服务器配置，本期不提供注册或用户管理。

## 验证

运行构建、类型、lint、`test:web` 与架构检查。路由测试覆盖独立登录地址、站内回跳、外部地址和循环跳转防护；隔离环境浏览器检查直接访问业务页、登录后返回、刷新、退出和会话失效跳转。
