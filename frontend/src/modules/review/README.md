## 规则

- 子采购行显示开票口径：采购数量、采购单位、含税金额；报关数量在说明中显示。
- 点击“查看”打开的子采购明细弹窗展示“销售订单汇率”（`salesOrderExchangeRate`），直接显示后端十进制字符串；缺失时显示“来源未提供”，不默认填 0 或 1。
- 子采购详情复用统一 `Dialog`，桌面最大宽度 1040px；数量与单位分开，来源说明跨整行。原始订单行在 `DataTable` 内独立上下滚动、固定表头；窄屏允许表格内横向滚动，短屏允许正文滚动，关闭按钮保持可见。
- 能否审核、状态、计数、筛选和分页均由后端返回；按钮使用后端 `allowed/reason`，点击后后端重新校验。
- 2026-10-27 起，列表读取后台持久化的计算快照。同步、审核或容差变化后，`notices` 提示后台计算中／失败重试；未更新账套暂时展示上次完成的单据快照和状态统计，后端清空幅度结论、关闭审核按钮并从异常及可自动审核计数中排除。完成后点击“刷新列表”读取新结果。`calculationStatus` 为 ready / pending / failed，`calculatedAt` 是上次完成的 UTC 时间；前端不计算、不回退到旧结论。
- 来源在页面打开后变化时，后端拒绝审核并提示刷新；页面显示真实错误，不自动重发。
- 未出库（缺真实报关单号或无子采购单）的报关单自 2026-10-23 起拉取时即跳过，页面不再提供"未出库"筛选。
- 页面顶部为概况卡（待审核及来源变化张数、申报幅度异常、可自动审核通过、本月审核通过，均为后端计数；四张均可点击筛选）。点击“本月审核通过”切换到“审核通过”列表并重置至第一页，保留查询条件；卡片数量仍按北京时间自然月统计，列表展示全部审核通过记录。采购单价超出人民币报关单价容差的报关单主行左侧橙色提示条并带“申报幅度异常”标签，可自动审核的带“可自动审核”标签；列表卡片标题右侧为状态切换，查询栏内嵌于卡片。
- 勾选框只在点击“批量审核通过”进入批量模式后出现（“取消批量”退出），只对后端允许审核的报关单开放；“确认审核通过（N）”打开确认窗口。
- 批量审核只提交当前页已勾选的报关单，窗口写明范围；结果按后端返回逐张展示，跳过的显示原因，完成后重新读取列表。
- 第 4c 步接入开票任务前，审核通过只保存审核记录与冻结行，不生成任务；页面说明已标明。

## 紧凑对照表（2026-10-26）

仅保留报关单主行的展开/收起。申报抬头与销售单号集中在主行；展开即展示全部报关行及其关联子采购行，共用母采购单号、子采购单号、货源地、供应商、品名、型号、数量、单位、单价、金额列。白底报关、浅蓝采购，同时保留来源文字；订单口径与本次口径明确区分，未定位的子采购行列在表尾并提示。金额与申报幅度直接展示后端结果。

申报幅度按单价显示：人民币报关单价对比合并采购单价（关联采购含税总金额 / 总数量）。`UnitPriceMargin` 显示两项后端单价；仅后端判定采购单价超出报关单价容差（`marginStatus=negative`）时突出异常。容差内按 `ok` 展示“精度范围内一致”、实际差额和容差，保留真实幅度（可为负数），不显示异常徽标或异常底色；前端不计算容差，不以百分比是否小于零自行判断。无法计算保留后端原因。

同一报关行的同子采购单号、供应商、品名、单位由后端合并，前端展示汇总数量、金额及加权单价，并标记“合并 N 行”。采购详情弹窗使用统一 DataTable 展示 `members` 原始数量、单价与金额；前端不自行求和，审核仍以原始行执行。

复用统一组件库 `DataTable` 的 `density="compact"` 与 `rowTone`，窄屏在表格容器内滚动。删除旧 `PurchaseRows` 卡片、树形连线及报关行折叠状态。单张/批量审核和采购明细弹窗入口保留。后端只补充 `salesOrders`、`originPlace`、`parent` 展示字段，不改审核或金额计算规则；字段需后端重启后生效。

## 申报幅度（2026-10-23）

报关行最后一列“申报幅度”显示后端计算值及报关／合并采购人民币单价；仅后端判定超出容差时标注异常，无法计算时显示“—”及原因，不显示 0。

## 去掉 NS 环境筛选（2026-10-26）

上线只同步 NS 正式环境，财务核对查询栏不再提供 NS 环境 / 账套筛选，地址里的 `account` 参数也不再读取（旧链接带 `?account=` 时按不限处理）。后端查询参数保留为可选，不传即不限；列表行内的 NS 环境文字仍照常显示。

## 报关单搜索（2026-10-28）

搜索栏拆为供应商、CD 号、子采购单号三个输入框；只展示框内提示，保留隐藏的可访问标签。复用 `SearchInput`，支持部分内容、逗号/分号分隔及粘贴多行。查询或回车提交给后端，清空恢复三个空条件并回到第一页；计数、筛选、分页仍由后端完成。旧混合关键词和供应商下拉已从搜索栏移除，响应供应商选项保留兼容旧调用。
