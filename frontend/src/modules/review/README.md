## 规则

- 2026-11-10 新增“单位不一致”概况卡，位于“申报幅度异常”之后，展示后端 `counts.unitMismatch`。点击提交 `status=unit_mismatch`，保留其他查询条件并回到第一页，列表标题为“报关单 · 单位不一致”。两类独立分类：只有实际单价超容差才显示“申报幅度异常”标签并进入对应卡片；单位不同显示“单位不一致”，数量不同显示“数量不一致”，两者均不冒充幅度异常。同单不同明细存在多种问题时并列展示后端标记，并进入对应筛选。卡片继续复用 `StatGrid` 自适应换行。

- 单张“整单审核通过”成功后自动关闭审核弹窗并重新读取列表；失败时保留窗口、备注和错误原因，不自动重试。批量全部成功时自动关闭，有跳过或失败项时保留逐张结果窗口。列表不再显示审核成功说明或顶部黄色账套计算说明条；计算未完成时后端仍关闭审核入口，禁用原因保留在对应按钮，真实请求失败正常显示。

- 子采购行显示开票口径：采购数量、采购单位、含税金额；报关数量在说明中显示。
- 点击“查看”打开的子采购明细弹窗展示“销售订单汇率”（`salesOrderExchangeRate`），直接显示后端十进制字符串；缺失时显示“来源未提供”，不默认填 0 或 1。
- 子采购详情复用统一 `Dialog`，桌面最大宽度 1040px；数量与单位分开，来源说明跨整行。原始订单行在 `DataTable` 内独立上下滚动、固定表头；窄屏允许表格内横向滚动，短屏允许正文滚动，关闭按钮保持可见。
- 能否审核、状态、计数、筛选和分页均由后端返回；按钮使用后端 `allowed/reason`，点击后后端重新校验。
- 2026-10-27 起，列表读取后台持久化的计算快照。同步、审核或容差变化后，未更新账套暂时展示上次完成的单据快照和状态统计，后端清空幅度结论、关闭审核按钮并从异常及可自动审核计数中排除；前端保留对应禁用原因，不显示顶部 `notices` 黄色说明条。完成后点击“刷新列表”读取新结果。`calculationStatus` 为 ready / pending / failed，`calculatedAt` 是上次完成的 UTC 时间；前端不计算、不回退到旧结论。
- 来源在页面打开后变化时，后端拒绝审核并提示刷新；页面显示真实错误，不自动重发。
- 未出库（缺真实报关单号或无子采购单）的报关单自 2026-10-23 起拉取时即跳过，页面不再提供"未出库"筛选。
- 页面顶部为六张可点击的概况卡：待审核及来源变化张数、申报幅度异常、单位不一致、可自动审核通过、海关审核通过、本月审核通过，均为后端计数。点击“海关审核通过”提交 `status=customs_approved`，按当前有效海关审核筛选，不限制财务审核状态；显示 `counts.customsApproved`，保留查询条件并回到第一页。点击“本月审核通过”切换到“审核通过”列表并重置至第一页，保留查询条件；卡片数量仍按北京时间自然月统计，列表展示全部审核通过记录。采购单价超出人民币报关单价容差的报关单主行左侧橙色提示条并带“申报幅度异常”标签，可自动审核的带“可自动审核”标签；列表卡片标题右侧为状态切换，查询栏内嵌于卡片。
- 勾选框只在点击“批量审核通过”进入批量模式后出现（“取消批量”退出），只对后端允许审核的报关单开放；“确认审核通过（N）”打开确认窗口。
- 批量审核只提交当前页已勾选的报关单，窗口写明范围；结果按后端返回逐张展示，跳过的显示原因，完成后重新读取列表。
- 财务审核保存审核记录与冻结行；海关与财务两项当前版本均通过后，才自动生成开票任务。

## 紧凑对照表（2026-10-26）

仅保留报关单主行的展开/收起。申报抬头与销售单号集中在主行；展开即展示全部报关行及其关联子采购行，共用母采购单号、子采购单号、货源地、供应商、品名、型号、数量、单位、单价、金额列。白底报关、浅蓝采购，同时保留来源文字；数量标注报关口径，采购单价旁注明同一报关单位，未定位的子采购行列在表尾并提示。金额与申报幅度直接展示后端结果。

申报幅度与采购价由后端计算。报关行“未含税采购单价”列仅显示 `purchaseUnitPriceUsd` 数值；独立“采购数量”列显示报关行的 `purchaseOrderQuantity` 合计、子采购行的原 `purchaseQuantity`，缺失不回退报关数量。移除单价下的 USD／单位及“下单数量”附注；缺值就近显示 `purchasePriceNote`，不能展示旧报关行采购价作为兜底。计算口径为：关联采购明细逐行按真实税率还原未税金额，合计除以采购下单数量合计，再按对应销售单汇率折为 USD。采购数量与报关数量、单位不同，也不改变分母。前端不除税、汇总或换汇。

末列表头统一为“申报幅度”，只显示后端幅度及必要的异常、无法计算原因，删除重复报关价、采购价、USD／单位和公式说明；子采购的“查看”按钮保留，申报单价列的试算标记保留。对照表内申报单价、子采购单价及未含税采购单价统一四舍五入显示两位小数（如 `2.184869` 显示 `2.18`、`1` 显示 `1.00`），只格式化十进制字符串，不改变接口、数据库快照与后台计算精度。后端仍按未舍入人民币差额判断既有 0.10 元容差，前端不以百分比正负推断异常。数量、单位待核对时幅度为“—”并显示原因，采购价仍独立展示。后台 `review-v17` 按母采购单对应明细的采购单位与报关单位校验，原始报关单位及数量差异不再阻止幅度计算，补算期间隐藏旧采购价；旧来源缺少母采购单位名称或采购税率时需重新同步，详见[后端规则](../../../../backend/modules/review/README.md#采购未税-usd-单价与申报幅度2026-11-19)。

单位或数量不一致时，申报幅度列显示“—”与对应徽标；单位不一致时另以“报关：千克”“采购：包”两行短描述显示后端的 `declaredPriceUnit`、`originalPriceUnit`，其中采购单位来自母采购对应明细，多个不同单位按后端结果展示；缺失显示“未提供”。完整原因放入悬停说明和读屏标签，避免长说明撑高表格行。

## 双审与开票进度

财务核对和报关单比对复用 `ApprovalProgressCells`，在主行并列展示财务审核、海关审核、开票进度和下一步。财务的申报信息和海关的回执信息分别归在一列，原有核对明细仍可展开。状态、阻塞原因和有效任务 ID 来自列表接口。

有目标页面权限时，下一步按真实报关单号精确查询对页并展开对应记录。未导入回执时可从财务页打开对应单号的导入弹窗。财务页在「下一步」提供「查看对应海关回执」或「导入海关回执」，海关页在「下一步」提供「查看对应财务核对」，三个入口使用同样的蓝色文字按钮。展开明细仍提供实际任务入口，存在多个任务时逐个列出。

开票进度为「已生成任务」时，财务核对主行省略「查看对应海关回执」。单个任务从主行的「查看任务」进入，多个任务从展开区逐个进入。

## 报关单比对按差异类型筛选（2026-11-25）

`components/CustomsSearchForm.tsx` 新增“差异类型”下拉（全部类型 / 数量不一致 / 单位不一致 / 总价不一致 / 品名缺行），随查询提交 `difference`，与状态切换条同时生效；选项张数来自后端 `counts`，一张回执可属多类，前端不合计。概况第三张卡由“数量或单位不一致”更名为“有差异”。有差异回执展开后的提示改为“不能自动审核；人工核对后可审核，差异说明选填”。
