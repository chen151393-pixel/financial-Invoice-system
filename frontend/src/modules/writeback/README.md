# NS 回写页面

`/writeback` 为真实任务列表，`/writeback/:requestId` 显示回写任务详情。沿用既有路由参数名，值为后端任务 ID。

- 列表由后端搜索、筛选和分页；状态、原因和允许动作由后端返回。
- 详情展示审核分配、候选账单、目标方案和审计记录。金额保持十进制字符串。
- 人工确认支持多账单拆分、归属依据和实际 NS 子公司核实。请求携带当前 revision 与稳定 requestId；失败不伪装成功、不自动重试确认。
- 匹配发票详情通过公开 API 显示整票就绪原因和当前任务链接；可重新检查历史发票。
- 已删除原手工预览/执行演示 API、demo1/demo2 数据与不再引用的旧组件和样式。历史演示 URL 不再有模拟成功行为。
- 方案冻结后显示“NS 回写预览”（`components/WritePanel.tsx`）：逐账单写前、本次、写后累计与明细差额，金额全部为后端字符串。累计与明细不一致时须勾选核对后“确认回写预览”。
- 仅当后端 `actions.execute` 为真时显示“回写到 NS”，确认弹窗说明写入对象、范围和不可自动撤回；不允许时显示后端原因（开关、白名单、接口未配置）。
- 结果不明或部分写入时显示“核实 NS 写入结果”（`components/ResolveForm.tsx`），只提交核实结论与依据；没有重试或直接重发按钮。“NS 没有任何写入”选项仅在后端允许时出现。

接口与部署见 [后端模块](../../../../backend/modules/writeback/README.md)、[部署说明](../../../../docs/ns-writeback-prepare.md)。验证：前端 lint、typecheck、build，`tests/writeback.test.mjs` 覆盖实际接口参数（含预览确认、写入、核实）、错误与关键状态展示。
