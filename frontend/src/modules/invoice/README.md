# 进项发票页面

架构 v2 第 4d 步按模块目录重排并改用新接口。后端规则见[后端 invoice 模块](../../../../backend/modules/invoice/README.md)。

| 位置          | 页面                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------- |
| `/invoices`   | `pages/InvoiceListPage.tsx`：搜索、票面状态与日期筛选、分页、按币种汇总、比对状态、票面详情 |
| `/sync/lemon` | `pages/InvoiceImportPage.tsx`：由同步页嵌入的 Excel 导入（拖入或选择文件 → 预览 → 确认）    |

## 文件

| 目录               | 内容                                                                                                                                                                         |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api/invoice.ts`   | 列表、详情、导入配置、预览、确认、读取本地文件为 base64                                                                                                                      |
| `types/invoice.ts` | 与后端 VO 一致的类型                                                                                                                                                         |
| `components/`      | `InvoiceSummary`（汇总）、`InvoiceFilters`（筛选）、`InvoiceTable`（列表）、`InvoiceDetailDrawer`（票面详情抽屉）、`ImportResultView`（导入核对表）、`format.ts`（金额展示） |

## 规则

- 列表、筛选、分页与按币种汇总由后端完成；金额只调整展示格式，不换算、不计算。
- 比对状态（未比对 / 待审核建议 / 部分比对 / 已比对）与建议置信度来自 matching 模块 `POST /api/matching/summaries`，读取失败单独提示，可刷新重试。
- "比对"进入 `/matching/:invoiceId`；票面详情在无购买方时显示“来源未提供”，并展示后端 `detailStatusLabel`；API 只有票头时明确提示商品明细待补齐。
- 可抵扣税额、待匹配金额、异常金额尚无业务来源，显示"尚未接入"。已移除不起作用的禁用标签与筛选按钮（主体、会计期间、币种、匹配关系）及无后续操作的勾选列。
- 导入：重复跳过、冲突整批不写入；确认后自动生成比对建议。
