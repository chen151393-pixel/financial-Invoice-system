# 进项发票页面

## 票面状态与筛选

票面状态下拉框常驻查询栏：全部、正常、红字发票、已被红冲、作废、未知。选择后点击“查询”，复用后端 `status` 条件；列表分页与顶部统计使用相同筛选，日期条件继续位于“更多筛选”。

仅标签突出：红字发票为红色，已被红冲为橙色，作废为灰色边框；行背景、边线和金额保持普通样式。前端只根据后端 `displayStatus` 渲染，不根据金额推断状态；`sourceStatus` 保留原始入库状态。详情顶部及票面状态单元格同步使用标签，提示来自后端 `statusNotice`。没有核实的关联关系时不创建关联链接。

比对入口保留用于查看历史记录；原有后端匹配限制不变。状态样式独立在 `components/invoice-status.css`，配色使用公共语义变量；整行状态样式和原“更多筛选”中的重复状态控件已删除。

验证覆盖标签分类、查询栏筛选、详情标签及后端列表和统计的一致性。浏览器安全策略阻止本地页面访问，未完成桌面及小屏实际视觉验收。

## 重新拉取商品明细

列表行操作支持单张补拉；默认不显示补拉操作栏与常驻说明，勾选当前页发票后才显示批量补拉按钮（最多 100 张）。切换筛选或页码后清空选择。查询补拉状态仅在请求执行中或结果待核实时显示。按钮可用性与禁用原因来自后端，当前绑定账套须与原票一致。Excel 和默认版接口票不支持此入口。

`api/detail-refresh.ts` 调用 sync 的定向补拉和原结果查询接口；`hooks/useDetailRefresh.ts` 管理选择、执行状态和请求编号；`components/InvoiceDetailRefresh.tsx` 展示真实结果与逐票未补齐原因。响应中断后在会话存储保留请求编号，点击“查询补拉状态”只读原结果，不能自动重放保存。完成后刷新列表、金额统计与比对状态；完整明细仍须人工确认匹配。

接口参数仅为发票 ID 列表和请求编号，不上传日期、账套、票面正文或金额。复用现有同步和版本保存，无新增路由或迁移。测试见 `tests/invoice-detail-refresh.test.mjs`。

架构 v2 第 4d 步按模块目录重排并改用新接口。后端规则见[后端 invoice 模块](../../../../backend/modules/invoice/README.md)。

## 规则

- 列表、筛选、分页与按币种汇总由后端完成；金额只调整展示格式，不换算、不计算。
- 比对状态（未比对 / 待审核建议 / 部分比对 / 已比对）与建议置信度来自 matching 模块 `POST /api/matching/summaries`，读取失败单独提示，可刷新重试。
- "比对"进入 `/matching/:invoiceId`；票面详情在无购买方时显示“来源未提供”，并展示后端 `detailStatusLabel`；API 只有票头时明确提示商品明细待补齐。
- 顶部通过 `GET /api/matching/invoice-totals` 展示价税合计、票面税额、待匹配金额、待复核金额；统计覆盖当前已应用筛选的全部页，按币种分开。前端只格式化十进制字符串，不计算金额。原“可抵扣税额”“异常金额”占位改为已接入且口径明确的指标。
- 待匹配金额为正常发票含税金额减有效确认分配（逐票不小于零），含尚待补明细及待复核部分；待复核金额为已确认但失效或待复核的分配金额，包括作废、红冲后的历史占用。两者可能重叠，不相加。
- 统计独立处理加载、空结果、失败和刷新；筛选、分页与返回缓存页面后重新读取，忽略旧请求响应。读取失败显示错误而非零，筛选无发票才显示零。
- 导入：重复跳过、冲突整批不写入；确认后自动生成比对建议。

## 账套筛选

进项发票查询栏常驻“账套”下拉框，默认“全部账套”。选项来自 `GET /api/sync/lemon/invoices/accounts` 的本地已入库账套与名称；不调用上游、不影响同步页所选账套。选择后点击“查询”，列表与金额统计同时提交 `account`，从第一页显示；翻页保留条件，“更多筛选 → 重置”恢复全部。未应用的条件有提示，选项加载或失败有独立反馈，失败可用“刷新数据”重试。Excel 和名称缺失的历史账套按后端标签展示。

## 匹配状态筛选（2026-10-27）

列表卡片的查询栏下方有“匹配状态”分段：全部 / 已匹配 / 部分匹配 / 待审核 / 待复核 / 未匹配 / 不参与比对，张数由后端按其他筛选条件统计。列表改为请求 matching 的 `POST /api/matching/invoices/query`（列表、张数、本页比对状态一次返回，不再单独请求 `/summaries`）；所选状态写入地址 `?match=`，切换时回到第 1 页。概况卡与分布图仍按票面条件统计，不随匹配状态变化。
